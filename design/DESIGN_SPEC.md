# 소비나침반 디자인 명세 v2.1

이 문서는 제공된 `소비나침반_디자인_미리보기_v2.1.html`과 `소비나침반_디자인_API계약_검토서_v2.1.docx`를 기존 React 화면에 병합하기 위한 요약 명세다. 미리보기의 고정 `fetch` 대역은 시각 참고용이며 실제 API·계산·연동 검증의 근거로 사용하지 않는다.

## 시각 체계

- 캔버스 `#F8F9F7`, 표면 `#FFFFFF`, 본문 `#26322E`, 보조 `#65716B`
- 주 행동 `#BF4933`, 주 행동 hover `#A83926`, 옅은 강조 `#FFF3EF`
- 신뢰/보조 `#315E4F`, 보조 배경 `#EDF4EE`, 경계 `#E3E8E1`, 포커스 `#276F68`
- 시스템 한국어 글꼴을 사용하고 별도 폰트 파일·이미지를 번들에 넣지 않는다.
- 카드와 패널은 둥근 모서리와 얕은 그림자를 사용하되, 레퍼런스 브랜드·카피·CSS를 복제하지 않는다.

## 화면 구조

1. S01 장소 탐색: 자연어 입력, 예시 문장, 저장 안내
2. S02 내 조건: 지역·업종·목적·인원·예산·방문 시각·분위기, 초안/확정 경계
3. S03 추천 장소: 서버 순서 최대 5개, 서버 가격·잔여금액·추천 이유, 최대 3개 비교
4. S04 추천 근거: 가격 구성, 출처 ID/관측일, 장소와 상권 집계 구분
5. S05 예산 비교: 장소별 대안 비용·잔여금액·가정. 대안 비용을 합산하지 않는다.

## 데이터 정직성

- 프론트는 금액·잔여금액·추천 순서를 계산하거나 보정하지 않고 서버 응답을 표시한다.
- `coordinates=null`인 demo에서는 지도 핀·경로·가상 좌표를 만들지 않고 지도 대기 상태를 표시한다.
- 사진 URL·권리 정보가 없으면 사진을 만들지 않고 업종 기호와 사진 미제공 상태를 사용한다.
- 지역혜택·결제·실시간 혼잡·카드매출·실제 장소 출처는 연결된 것으로 표현하지 않는다.
- 알 수 없는 가격·영업·출처는 `확인 필요`, `미확인`, `연결 대기` 상태로 남긴다.

## 반응형·접근성

- 목표 폭은 360/390/768/1280px이며 760px 이하에서 단일 열로 전환한다.
- 추천 화면은 목록과 상태/비교 패널을 분리하고, 작은 화면에서는 패널을 목록 아래로 이동한다.
- 본문 건너뛰기 링크, 명시적 label, 오류 `role=alert`, 상태 `role=status`, 키보드 포커스 링을 제공한다.
- 표는 가로 스크롤 컨테이너 안에 두며, 필수 정보가 작은 화면에서 잘리지 않게 한다.
