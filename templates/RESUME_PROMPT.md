# 재개 지시문

이전 실행의 AGENT_STATUS.json, BLOCKERS.md, DECISIONS.md, reports/FINAL_REPORT.md와 현재 파일 변경을 먼저 읽어라.

이번에 제공된 입력: [파일·설정 이름 또는 사용자 결정]
해소할 문제 ID: [BLK-XXX]
승인된 목표와 범위: [P0/P1/해당 분기]

입력 충족과 사용권·권한을 먼저 확인하고, 충족되지 않으면 부족한 부분을 구체적으로 다시 요청하라. 충족되면 기록된 재개 위치부터 수행하라. 이미 완료한 기능을 불필요하게 재구현하지 말고 해당 단계와 영향받는 회귀 테스트를 실행하라. 기존 완료 결과를 보존하라.

새 장애가 생기면 AGENTS의 중단·부분 진행·재요청 규칙을 동일하게 적용하고 종료 보고와 체크포인트를 갱신하라.
