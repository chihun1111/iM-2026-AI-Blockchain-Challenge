## 별도 확인이 필요한 불일치

| 항목 | 문서/안내 | 실제 HTML 파일 입력 | 처리 |
|---|---|---|---|
| 붙임 양식 | 공식 배포 파일은 `.hwpx` | `.pdf,.hwp,.jpg,.jpeg,.png` | PDF로 내보내는 방안을 우선 검토하고 주최 측 확인 |
| 소스 코드 | 화면 설명은 전체 소스 ZIP | `.pdf,.hwp,.jpg,.jpeg,.png` | ZIP 허용 여부나 대체 제출 형식을 주최 측에 확인 |
| 프로토타입 | 공고·FAQ는 코드 또는 구현/시연 영상 | 상세 페이지는 구현 코드 중심 표현 | 영상만으로 가능한지, 코드도 필수인지 확인 |
| 영상 규격 | 제출 대상으로 언급 | 길이·해상도·용량 지침을 찾지 못함 | 주최 측 확인 |
