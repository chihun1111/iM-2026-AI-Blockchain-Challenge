# 기본 보안 점검 보고서

확인일: 2026-09-19

상태: `PASS_WITH_DEMO_LIMITS`

## 확인 항목

- 외부 호출 기본값은 `ALLOW_EXTERNAL_CALLS=false`이며, 키가 없는 상태에서 Gemini 호출을 실행하지 않는다.
- Gemini 키는 서버 환경변수에서만 읽고 `x-goog-api-key` 요청 헤더로 전달한다. 프런트엔드 `VITE_` 변수에는 비밀키를 넣지 않는다.
- React 렌더링에서 raw HTML 주입 API를 사용하지 않는다. 사용자 입력과 API 문자열은 React 기본 이스케이프 경로로 렌더링한다.
- CORS 기본 허용 origin은 로컬 프런트엔드 두 주소로 제한되어 있고 환경변수로 명시적으로 바꿀 수 있다.
- API는 Pydantic 검증, 500자 자연어 제한, 16KB 요청 본문 제한, 고정된 오류 envelope를 사용한다.
- 클라이언트 저장소에는 장소 ID·스냅샷 ID·저장 시각만 보관하고 원문 자연어·키·가격 원본을 저장하지 않는다.
- SQLite 접근은 서버가 검증한 snapshot/place ID를 사용하고, 예산 금액은 클라이언트가 보낸 가격이 아닌 서버 DB에서 재계산한다.

## 데모 한계

인증·사용자별 권한, rate limit, 운영 HTTPS·보안 헤더, 감사 로그, 키 회전 정책은 P0 로컬 데모 범위에 포함하지 않았다. 공개 배포나 실제 데이터·Gemini 연결 전에는 별도 운영 보안 검토가 필요하다.
